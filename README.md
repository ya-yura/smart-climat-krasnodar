# Смарт-Климат — Краснодар

Production-like одностраничный сайт для компании «Смарт-Климат»: подбор,
продажа и монтаж кондиционеров для квартиры, дома и офиса.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Для проверки production-версии:

```bash
npm run build
npm test
npm run lint
```

## Структура

- `app/page.tsx` — одностраничный сайт и интерактивный сценарий подбора.
- `app/globals.css` — адаптивная стилистика и визуальная система.
- `public/favicon.svg` — нейтральная иконка сайта.
- `.github/workflows/pages.yml` — сборка и публикация на GitHub Pages.
- `scripts/build-pages.mjs` — превращает server-rendered HTML и клиентские
  ассеты в автономный Pages-артефакт.
- `tests/rendered-html.test.mjs` — проверка серверного HTML после сборки.

## Публикация на GitHub Pages

После первого push workflow `Deploy to GitHub Pages` соберёт проект и
опубликует его через GitHub Pages. В настройках репозитория в разделе
**Settings → Pages** должен быть выбран источник **GitHub Actions**.

Workflow использует production-сборку vinext, формирует `dist-pages` и
загружает его как артефакт Pages. Проект не использует сервер, базу данных или секреты, поэтому
демо работает как автономная статическая страница.
